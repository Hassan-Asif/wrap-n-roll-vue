# Wrap N Roll — Vue 3

Converted from the provided React-in-HTML storefront to Vue 3 + Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`

## Notes
- Cart persists in localStorage.
- Checkout is a front-end demo. It does not send orders to a database or notify the store.
- Card payment is not integrated; connect a payment provider before accepting card payments.
- Change the WhatsApp number in `src/App.vue` under `CONFIG`.
